Le jeu propose 25 améliorations uniques pour la classe Mage, appelées augments. Chaque augment transforme le personnage d'une façon particulière — avec un côté positif, un côté négatif, et un impact sur son score d'IQ. Toutes ces données sont stockées dans des fichiers de configuration externe (Data Tables), ce qui permet de les modifier ou d'en ajouter facilement. Les choix du joueur sont mémorisés automatiquement et partagés avec tous les joueurs connectés, même en changeant de niveau.

The game features 25 unique upgrades for the Mage class, called augments. Each augment transforms the character in a specific way — with a positive side, a negative side, and an impact on their IQ score. All data is stored in external configuration files (Data Tables), making it easy to add or modify content. Player choices are automatically saved and shared with all connected players, even when changing levels.

Le système Enhanced Input d'Unreal Engine 5 permet de définir et organiser tous les contrôles du jeu (touches clavier, boutons de manette) de façon flexible et découplée du code. Chaque action de jeu (se déplacer, interagir, ouvrir le menu...) est mappée indépendamment, ce qui facilite la reconfiguration des touches par le joueur et la prise en charge de plusieurs périphériques à la fois.

Unreal Engine 5's Enhanced Input system allows you to define and organize all game controls (keyboard keys, gamepad buttons) in a flexible, code-decoupled way. Each game action (move, interact, open menu...) is mapped independently, making it easy for players to remap keys and supporting multiple devices simultaneously.

Ce projet consistait à transformer un mini-ordinateur (Raspberry Pi 400) en vrai serveur Linux, en équipe de 3 personnes avec des rôles bien définis. L'un gérait les comptes utilisateurs et les permissions d'accès aux fichiers. Un autre installait une base de données et un serveur web pour héberger des pages dynamiques. This project involved turning a mini-computer (Raspberry Pi 400) into a real Linux server, as a team of 3 with defined roles. One managed user accounts and file permissions. Another installed a database and a web server to host dynamic pages. The third handled secure remote connections and system log analysis. The final grade was determined automatically by an evaluation script — which made precision essential on every single command.
